# EasyMoney

Gerencie suas finanças pessoais de forma simples e intuitiva.

## O que é o EasyMoney?

EasyMoney é um aplicativo web que ajuda você a controlar suas despesas, acompanhar seu orçamento e tomar decisões financeiras mais inteligentes. Perfeito para uso individual ou familiar.

## Principais Funcionalidades

- **Controle de Despesas**: Registre todas as suas transações de forma rápida e fácil
- **Orçamento Mensal**: Defina limites de gastos e acompanhe seu progresso
- **Categorias Personalizadas**: Organize suas despesas do seu jeito
- **Visão Anual**: Planeje e visualize suas finanças ao longo do ano
- **Notificações**: Receba alertas quando estiver perto do limite do orçamento
- **Uso em Família**: Compartilhe o controle financeiro com membros da família

## Como Usar

### Instalação

1. Clone o repositório
2. Instale as dependências:
   ```
   npm install
   ```
3. Configure o Firebase (arquivo `.env` com suas credenciais)
4. Inicie o aplicativo:
   ```
   npm run dev
   ```

### Começando

1. Crie sua conta ou entre com suas credenciais
2. Configure suas categorias de despesas
3. Defina seu orçamento mensal
4. Comece a registrar suas transações

## Tecnologias

Construído com React e Firebase para uma experiência rápida e confiável.
